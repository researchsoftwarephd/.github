# Research Software PhD Lectures

This GitHub page contains repositories for the **Research Software** course from the
[Doctorate in Informatics](https://www.ulusofona.pt/en/lisboa/phd/informatics)
at [Lusófona University](https://www.ulusofona.pt/).

_Note: this course is currently not running, with its last instance taking place in 2023/24_

- [deep-unfolding](https://github.com/Salahberra2022/deep-unfolding) (paper in preparation)
- [agenet](https://github.com/cahthuranag/agenet) ([preprint](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=5010747))
